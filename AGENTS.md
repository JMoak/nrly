# nrly engineering

Keep the Python kernel independent of Keywork and Plaia. CLI and MCP use the same validated
application operations. Existing repositories are read-only unless separately scoped.

Model execution must be real and provenance explicit. Engineering fixtures never establish
general model quality. Failed, cancelled, interrupted, or unscored cases cannot count as passes.
Preserve base weights, scope hooks, and retain unsuccessful attempts.

Use strict typed contracts, pinned dependencies, bounded artifacts, and meaningful tests.
Run Ruff, pytest, and type checks appropriate to changed modules. Do not hide failed checks.
Do not commit, push, publish, or register services without the user's explicit instruction.

Coordinate shared contracts and environment changes with the integrating agent. One owner
installs dependencies and schedules GPU work. Respect assigned file ownership.
