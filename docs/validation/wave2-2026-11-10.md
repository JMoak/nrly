## Real model acceptance

See [Qwen evidence](wave2-qwen/README.md) and its artifact inventory. The pinned
`Qwen/Qwen3-0.6B` checkpoint ran on RTX 5090 using BF16, eager attention and the existing
CUDA environment. A pipeline combined low-rank update, rectangular scaling and a sparse
update across two layers. It produced **three net stored parameter changes**. Separate
inverse scaling operations produced zero net changes. Full-state restoration hashes
matched the original, and an incorrect base was refused.

The original end-to-end acceptance took 48.135 seconds. The fresh replay after stronger
CLI checks took 13.063 seconds and matched all seven flags: outputs, inspection,
identity, stable sample evidence, weight evidence, activation evidence, and overall
replay. The answers remained `2 + 3 = 5`, `OK.`, and `Paris`; only one passed the exact
scorer. **No language-model capability improvement was demonstrated.**
This Qwen recipe records no activation captures; its activation-equality flag compares
empty lists. Nonempty activation mismatch detection is covered by the CLI tests.
